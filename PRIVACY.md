# Privacy note for teachers, parents and learners

KitBench is a website that runs entirely inside your browser.

- **No accounts on a server.** There is no database and no login server. A learner profile is a name and a 4-digit PIN saved on the device.
- **Nothing is sent anywhere.** Names, PINs, stars, blocks and projects are stored only in the browser on that device (localStorage). The site makes no requests to other websites and has no advertising, analytics or tracking.
- **What is stored on the device.** Learner names (use first names or nicknames), a scrambled form of each PIN, mission stars and times, the blocks and code a learner wrote, and the robot kit settings.
- **Who can see it.** Anyone who uses the same device and browser can open the learner list. The PIN only stops classmates from changing each other's stars. It is not strong security, so please never use a real password as a PIN.
- **Deleting data.** The teacher can delete a learner from the Teacher panel. Clearing the browser's site data removes everything.
- **Backups.** The Teacher panel can download a backup file. That file contains learner names and stars, so keep it somewhere safe.
- **Please do not type** surnames, phone numbers, addresses, photos or any other personal details into KitBench.

The site is served by GitHub Pages, which, like any website host, may keep ordinary server logs of visits. See GitHub's own privacy statement for details.
